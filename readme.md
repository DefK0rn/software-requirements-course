### Список доступных статусов задач
- `Новая(ый)` Начальный статус
- `Системный анализ` Формализация и описание требований и работ
- `Бэклог` Успешно пройден системный анализ, задача согласована для работы
- `В работе` Работа по задаче, не связанная с непосредственной разработкой
- `Разработка` Непосредственная разработка по описанным требованиям
- `В блоке` Заблокирована другой задачей и пока не может быть выполнена
- `Ревью` Техническое ревью команды разработки
- `Приемка` Тестирование или приемка результатов работы/разработки
- `Готово` Финальный статус завершенных и принятых работы по задаче
- `Отменен(а)` Финальный статус, когда принято решение отменить полностью задачу

### FAQ
- Для изменения таблицы переходов статусов под свой проект обратитесь к преподавателю в Tag.
- Для изменения справочника учета времени обратитесь к преподавателю в Tag.
- Для органиазции спринтов можно воспользоваться справочником категорий. Он размещен в настройках проекта и доступен для редактирования. Категория - спринт <номер> - назначается задаче, а список задач можно фильтровать по справочнику категорий.
- Для учета фактической разработки на статусе `В работе` используйте учет времени. В справочнике учета есть есть и иные виды работ.
